How a frame becomes a letter

1
Find the hand
MediaPipe returns 21 joint positions. The photo itself is thrown away.
2
Remove position and size
Points shift so the wrist sits at zero, then scale so the hand spans one unit.
3
Ask 100 trees
Each decision tree votes for a letter. The share that agree becomes the confidence.
4
Wait for a steady shape
Below 60% agreement nothing is shown. A letter is written only after it holds.

What it does not do

J and Z are missingBoth are drawn in the air. A single frame cannot capture a path.
Rotation is not handledLetters with a strong direction expect you to face the camera the way the data was recorded.
One pair of handsTwo sessions, one person, one right hand. Nothing here proves it generalises further.
Built with Python, scikit-learn and MediaPipe. The trained forest is exported to JSON and walked in JavaScript, so there is no server. Source on GitHub
